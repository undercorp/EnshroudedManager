# Enshrouded Manager

**English** · [Français](#français)

Install, update and manage an **Enshrouded dedicated server on Windows** — from a web page or a desktop app.

- **One installer, nothing else to install.** Pick where the tool and the server files go, choose the web interface, the desktop app or both. SteamCMD and the dedicated server (~8 GB) are then downloaded automatically, a base configuration is created and the server starts.
- **Automatic updates.** Every 10 minutes the published Steam build is compared with the installed one. When an update is out: clean stop (the world is saved), verified backup, `steamcmd app_update`, restart. If the backup fails, nothing is updated.
- **All server settings** of `enshrouded_server.json` (difficulty, player groups and passwords, day length…) in a form. *Apply* validates, backs up, writes and restarts the server. Unknown keys of the file are kept.
- **Backups** before every update, settings change and restore; restore or download them in one click.
- **Web and desktop stay in sync**; the desktop app shows Windows notifications for updates and crashes.
- French and English (chosen from the installer language, switchable in the *Tool* tab).

## Install

1. Download `EnshroudedManager-Setup-x.y.z.exe` from the [Releases](../../releases) and run it (administrator rights are required: it installs a Windows service).
2. Follow the wizard: install folder, server folder, web and/or desktop, interface password, server name and passwords.
3. At the end, open Enshrouded Manager: the server download progress is shown at the top. The server starts by itself when it is done.
4. To play from the Internet, forward the **query port (UDP 15637 by default)** on your router to this PC. The Windows firewall rule is created automatically.

The web interface is at `http://<server-ip>:8090` (port chosen in the installer). It is plain HTTP: keep it on your local network or behind a VPN such as Tailscale; do not expose it to the Internet.

Unattended install: `EnshroudedManager-Setup-x.y.z.exe /VERYSILENT /COMPONENTS=service,web,desktop /SERVERDIR=D:\EnshroudedServer /PASSWORD=… /SERVERNAME=… /SLOTS=8 /PORT=8090 /QUERYPORT=15637 /FRIENDPASSWORD=… /ADMINPASSWORD=…` (`/LANG=fr` or `/LANG=en`).

Running the installer again updates the tool in place and keeps the settings, the password and the backups. Uninstalling asks whether to also delete the backups and the server files (world saves included); the default answer is *no*.

## How it works

| Part | Role |
|---|---|
| `EnshroudedManager.Service` | Windows service (LocalSystem). Downloads SteamCMD and the server, runs `enshrouded_server.exe` as a child process, checks for updates, makes backups, serves the HTTP API and the web page. Without the web interface it only listens on `127.0.0.1`. |
| `EnshroudedManager.Desktop` | WinForms app, client of the same API (`http://localhost:<port>`). |
| `EnshroudedManager.Shared` | DTOs and the FR/EN text helper. |
| `installer/` | Inno Setup script. The wizard choices are handed to the service once through `data\setup.json`, deleted as soon as it is read. |

Clean shutdown: the service sends Ctrl+C to the server console, which saves the world and exits; it is killed only if it does not stop within 45 s.

Data lives in `<install folder>\data`: `manager.json` (settings, password hash), `backups\`, `logs\`.

Forgotten password: stop the service, run `EnshroudedManager.Service.exe --reset-password`, start the service; the password is asked again on the next sign-in.

## Build

Requirements: .NET 8 SDK and [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`).

```powershell
.\build.ps1 -Version 1.0.0
```

The installer is written to `dist\`. The app icon is generated by `assets\make-icon.ps1`.

## Français

Installe, met à jour et gère un **serveur dédié Enshrouded sous Windows**, depuis une page web ou une application de bureau.

- **Un seul installeur, rien d'autre à installer.** Choisissez où vont l'outil et les fichiers du serveur, l'interface web, l'application de bureau ou les deux. SteamCMD et le serveur dédié (~8 Go) sont ensuite téléchargés automatiquement, une configuration de base est créée et le serveur démarre.
- **Mises à jour automatiques.** Toutes les 10 minutes, la version publiée sur Steam est comparée à celle installée. Quand une mise à jour sort : arrêt propre (le monde est sauvegardé), sauvegarde vérifiée, `steamcmd app_update`, redémarrage. Si la sauvegarde échoue, rien n'est mis à jour.
- **Tous les paramètres** de `enshrouded_server.json` (difficulté, groupes de joueurs et mots de passe, durée du jour…) dans un formulaire. *Appliquer* vérifie, sauvegarde, enregistre et relance le serveur. Les clés inconnues du fichier sont conservées.
- **Sauvegardes** avant chaque mise à jour, changement de paramètres et restauration ; restauration ou téléchargement en un clic.
- **Web et bureau synchronisés** ; l'application de bureau affiche des notifications Windows (mises à jour, plantages).
- Français et anglais (selon la langue de l'installeur, modifiable dans l'onglet *Outil*).

> Projet non affilié à Keen Games. Enshrouded est une marque de Keen Games GmbH.

### Installation

1. Téléchargez `EnshroudedManager-Setup-x.y.z.exe` dans les [Releases](../../releases) et lancez-le (droits administrateur requis : il installe un service Windows).
2. Suivez l'assistant : dossier de l'outil, dossier du serveur, web et/ou bureau, mot de passe de l'interface, nom et mots de passe du serveur.
3. À la fin, ouvrez Enshrouded Manager : la progression du téléchargement du serveur s'affiche en haut. Le serveur démarre tout seul à la fin.
4. Pour jouer depuis Internet, redirigez le **port de requête (UDP 15637 par défaut)** de votre box vers ce PC. La règle du pare-feu Windows est créée automatiquement.

L'interface web est sur `http://<ip-du-serveur>:8090` (port choisi dans l'installeur). Elle est en HTTP simple : gardez-la sur votre réseau local ou derrière un VPN comme Tailscale, ne l'exposez pas sur Internet.

Relancer l'installeur met l'outil à jour en conservant réglages, mot de passe et sauvegardes. La désinstallation demande s'il faut aussi supprimer les sauvegardes et les fichiers du serveur (mondes compris) ; la réponse par défaut est *non*.

Mot de passe oublié : arrêtez le service, lancez `EnshroudedManager.Service.exe --reset-password`, redémarrez le service ; le mot de passe sera redemandé à la connexion suivante.

### Compilation

Prérequis : SDK .NET 8 et [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`), puis `.\build.ps1 -Version 1.0.0`. L'installeur est produit dans `dist\`.
